# Electromagnet Lab

Open index.html in a modern browser. No build step or server is needed.

Interactive lesson based on the supplied Building an Electromagnet presentation: 1.5–6.0 V, 25/50 wire turns, current, magnetic fields, two trials per configuration, averages, CSV export, and a concept check.

The model holds resistance at 10 ohms and core geometry fixed. Results are illustrative, not experimental measurements. Trial data stays in the browser; no student accounts or data are sent to a server.

Production path: https://potentell.com/electromagnets.html (published through the PotentELL website repository).

Verification: JavaScript syntax and behavior checks passed for voltage, turns, open circuit, trial averages, and quiz feedback. Browser rendering verification remains pending.
